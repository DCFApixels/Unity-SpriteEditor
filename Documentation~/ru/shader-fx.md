# Shader FX и Processor

Нажми **+ Shader FX** в настройках слоя, напиши `ApplyFX` и нажми **Apply**.
Код и параметры могут храниться прямо в документе. Чтобы обработать уже собранную композицию
ниже определённой позиции, добавь отдельный слой **Shader Processor**.

## Shader FX: первый фрагмент, параметры и подключение библиотек

Добавь параметр **Float** с именем `_Amount` и примени пример:

```hlsl
float4 ApplyFX(float2 uv, float4 color)
{
    return float4(lerp(color.rgb, 1.0 - color.rgb, saturate(_Amount)), color.a);
}
```

Параметры: Float, Color, Vector и Texture2D; их uniform-переменные генерируются автоматически.
Код и объявления остаются черновиком до Apply. При ошибке работает последний успешный вариант.
Undo/Redo восстанавливает код, курсор и выделение; восстановленный код тоже нужно применить.

`SampleInput(uv)` читает слой после предыдущих модификаторов. Возвращай straight RGBA:
прозрачность/смешивание применяются позже. Встроены `_MainTex`, `_MainTex_TexelSize`, `_InputSize`,
`_CanvasSize` (ширина, высота, 1/ширина, 1/высота) и `_PreviewScale`.
Не объявляй сгенерированные uniform-переменные повторно.

Стандартный `#include` поддерживает пути проекта/пакета и относительные пути.
Относительные начинаются от папки документа/FX, до первого сохранения — от Assets.
После правки библиотеки снова нажми Apply; после Save As в другую папку проверь пути.
Библиотеки должны подходить для этого окружения фрагментного шейдера.

**+ Reference** подключает внешний FX для совместного использования; **Embed** делает независимую копию внутри документа.
Save As и дублирование слоёв независимо копируют встроенные FX. Эффекты идут по порядку после Transform;
изменение значений параметров не генерирует шейдеры заново.

## Shader Processor: обработать нижний стек вместо одного слоя

Processor использует тот же ApplyFX/SampleInput, но получает нижнюю композицию.
При Normal Opacity смешивает исходный и обработанный RGBA; 100% заменяет источник.
Другие режимы смешивают его с результатом. Оба диапазона по умолчанию HDR; скрытие Processor отключает обработку.

В Pass Through он видит и внешний фон; изолированная группа ограничивает его своими детьми.
Отдельное превью и растеризация собирают нижних соседей на прозрачном фоне.
Processor разделяет цепочки обтравки, не служит участником или базой.
PSD запекает композицию, сохраняя исходные слои в скрытой папке Source Layers.
