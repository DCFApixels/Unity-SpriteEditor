# Кисть, карандаш и заливка

Выбери рисовальный слой **Drawing** и рисуй прямо на холсте.
**Brush** (`B`) подходит для мягких мазков, **Pencil** (`P`) — для чётких пикселей.
При попытке рисовать на другом типе слоя редактор предложит сначала его конвертировать.

## Настроить мазок

| Настройка | Что меняет |
| :--- | :--- |
| Size | Толщину мазка. Можно тянуть за название или использовать `[` / `]`. |
| Hard | Жёсткость края: меньшее значение даёт более мягкую кисть. |
| Step | Расстояние между отпечатками кисти: меньше — плавнее линия, больше — заметнее отдельные отпечатки. |

У карандаша нет жёсткости и шага. Для наконечника доступны **Circle**, **Square** и **Diamond**:
круг, квадрат и ромб. Приблизь холст, чтобы увидеть точный пиксельный контур.

## Цвет и стирание

Первый образец цвета — цвет рисования; `X` меняет два образца местами.
Зажми `Alt` и кликни или проведи мышью, чтобы взять цвет из изображения.
Для временного стирания кистью или карандашом зажми правую кнопку мыши.
Режим ластика также можно выбрать в настройках инструмента.

Настройки кисти и заливки сохраняются при переходе между слоями.
[Симметрия](symmetry.md) настраивается отдельно у каждого рисовального слоя.

## Прямые линии

Кликни и начни тянуть, затем зажми `Shift`, чтобы рисовать горизонтально или вертикально.
Для соединения точек кликни первую, затем зажми `Shift` и кликни следующую.
Так можно последовательно провести несколько прямых отрезков.

## Залить область

Выбери **Fill** (`G`) и кликни по области, которую хочешь закрасить.

| Настройка | Когда использовать |
| :--- | :--- |
| All Layers | Учитывать контуры всей видимой картинки, но заливать только активный рисовальный слой. Без галочки учитывается только он. |
| Contiguous | С галочкой заливается связанная область под кликом. Без неё — все подходящие цвета на слое. |
| Tolerance | Увеличь, чтобы захватить больше похожих цветов; уменьши, если заливка растекается слишком далеко. |
| Antialias | Смягчить край заливки. |
| Expand (px) | Немного завести заливку под контур, чтобы убрать тонкие зазоры. |

Заливка не повторяется через симметрию кисти. Чтобы заливать трансформированные копии
за исходной областью слоя, сначала выбери **Convert to Drawing → Apply Transform**.

[Выделение области](selection.md) позволяет рисовать и заливать только внутри нужной формы.
