# Normal Map

Начинай с **Simple**: он оставляет основные настройки, но не меняет сам алгоритм.
**Advanced** показывает весь набор. Возврат в Simple не сбрасывает дополнительные параметры;
если они изменены, окно показывает соответствующую подсказку.

## Из готовой карты высот

1. Добавь Normal Map над File, Drawing или Noise.
2. Оставь Input → Previous или назначь Target явно.
3. Выбери Generation → Height Map и нужный Source Channel.
4. Начни со Strength 4 и Smoothing 1 px; подбери силу рельефа.
5. Сохрани источник скрытым, если в результате нужна только карта нормалей.

Светлое означает высокое. Strength 0 даёт плоскую нормаль, Invert Height меняет направление высоты.
Для числовой линейной текстуры открой Advanced и выбери Input Space → Linear.
Color Values читает видимые значения RGB; альфа не зависит от цветового пространства.

## Из цветной текстуры

Выбери Generation → Texture. Этот режим оценивает высоту по контрасту на нескольких масштабах:
он не восстанавливает настоящую геометрию и не умеет надёжно отделять освещение от цвета материала.

В Advanced переключи Output → Height, чтобы сначала увидеть реконструкцию. Настрой
Fine / Medium / Large Detail и радиусы средней/крупной детализации.
Light Removal ослабляет широкие перепады яркости, но может убрать и настоящий крупный рельеф.
Верни Output → Normal перед сохранением карты нормалей.

## Настройки по назначению

| Блок | Настройки |
| :--- | :--- |
| Source | Канал высоты; Input Space; Ignore Transparent для нормализации сглаживания по альфе. |
| Surface | Strength, Smoothing, Invert Height, Edges; в Advanced — Derivative. |
| Height Levels | Black/White Level и Gamma для диапазона реконструированной высоты. |
| Texture Detail | Масштабы и веса деталей; используются только режимом Texture. |
| Output | Flip X/Y, Alpha, Normal/Height и Encoding. |

Edges управляет выборкой на границе независимо от Transform: Clamp, Repeat или Mirror.
Для бесшовного источника используй Repeat. Alpha → Opaque даёт сплошную карту;
Source сохраняет покрытие источника. Когда высота берётся из Alpha, прозрачность участвует как высота.

## Экспорт без искажения данных

Оставь Normal blend, opacity 1, исходный Swizzle и не добавляй цветовые FX.
Блендинг не нормализует векторы заново. Transform двигает картинку, но не поворачивает её нормали.

- **Packed Color:** PNG, TGA, PSD и отображение; импортируй PNG/TGA как Normal Map без преобразования из grayscale.
- **Linear Data:** сырые значения 0–1 для линейного EXR или Texture2D; на цветном превью выглядят иначе.

Flip Y нужен, если потребитель ожидает противоположное направление зелёного канала.
