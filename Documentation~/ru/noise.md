# Процедурный Noise

Noise пригодится для облаков, зерна, каменных узоров или основы карты высот.
Добавь **Noise** через меню слоёв и меняй настройки, наблюдая за изображением.

## Начать с узора

| Настройка | Что попробовать |
| :--- | :--- |
| Noise Type | OpenSimplex2 или Perlin для плавных переходов; Cellular для ячеек; Value для более простого случайного узора. |
| Seed | Получить другой рисунок с тем же характером. |
| Scale | Увеличить для мелких деталей, уменьшить для крупных форм. |
| Offset | Сдвинуть узор. |
| Fractal | FBm добавляет детали; Ridged подчёркивает гребни; PingPong создаёт повторяющиеся полосы. |
| Octaves | Добавить больше уровней детализации. |
| Domain Warp | Изогнуть и исказить узор; Strength задаёт силу. |

Для более тонкой настройки **Lacunarity** меняет соотношение размеров деталей,
а **Gain** — выраженность мелких деталей.
В Cellular попробуй **Distance**, **Return** и **Jitter**, чтобы изменить форму и регулярность ячеек.

## Цветная текстура или карта высот?

Выбери **Encoding → Color Values**, если шум нужен как видимое чёрно-белое изображение.
**Linear Data** подходит для карты высот или упаковки в каналы текстуры.

Чтобы получить рельеф поверхности:

1. Добавь Noise и выбери **Linear Data**.
2. Включи **Fractal → FBm**, начни с трёх октав и подбери Scale.
3. Добавь **Normal Map** над шумом и выбери **Generation → Height Map**.
4. В Advanced у Normal Map установи **Input Space → Linear**.
5. Настрой Strength и Smoothing. Меняй Seed у Noise, чтобы попробовать другую поверхность.

Превью **Tiled** помогает заметить швы, но не делает сам Noise бесшовным.
Следующий шаг — [Normal Map](normal-map.md).
