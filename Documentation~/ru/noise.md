# Процедурный Noise

Noise генерирует OpenSimplex2, OpenSimplex2S, Perlin, Value, Value Cubic или Cellular на GPU.
Выбери Seed, настрой Scale/Offset, добавь фракталы или Domain Warp. Чем больше Scale, тем мельче детали;
масштаб измеряется по короткой стороне холста. Перетаскивай подписи числовых полей или слайдеры для обновления превью.

**Color Values** выводит градации серого для просмотра, **Linear Data** сохраняет сырые 0–1 для масок,
карт высот и упаковки каналов. В RGB одно и то же значение, альфа равна 1. Хранятся параметры,
не снимки пикселей; экспорт использует те же координаты/seed в полном разрешении.
Tiled-превью повторяет результат, но сам Noise пока не является бесшовным.

## Подобрать характер шума

| Настройка | Когда менять |
| :--- | :--- |
| Noise Type | OpenSimplex2/Perlin — плавные переходы; Cellular — структура ячеек; Value — интерполированные случайные значения. |
| Seed | Другой рисунок при той же структуре. |
| Scale / Offset | Размер деталей и положение в пространстве шума, независимо от Transform слоя. |
| Fractal | FBm складывает октавы; Ridged выделяет гребни; PingPong складывает повторяющиеся переходы. |
| Octaves | Число уровней деталей, 1–8. Больше — дороже расчёт. |
| Lacunarity / Gain | Рост частоты и затухание амплитуды каждой следующей октавы. |
| Domain Warp | Искривляет координаты до вычисления шума. Strength задаёт силу искажения. |
| Encoding | Color Values для видимого серого, Linear Data для числовой маски/высоты. |

Weighted Strength меняет вклад октав в зависимости от результата шума.
Cellular Distance, Return и Jitter влияют на ячейки, а Ping Pong Strength — на Fractal → PingPong.
При смене режимов их скрытые настройки не становятся общими настройками других слоёв.

## Пример: процедурная карта высот

1. Добавь Noise и выбери Encoding → Linear Data.
2. Выбери Fractal → FBm, начни с трёх октав и подбери Scale.
3. Добавь Normal Map выше: Generation → Height Map, Input Space → Linear в Advanced.
4. Подбери Strength и Smoothing у Normal Map. Seed у Noise меняет рисунок без ручной перерисовки.

Для большого холста генерация выполняется прямо на GPU в запрошенном разрешении;
Noise не использует дополнительный двухэтапный алгоритм уточнения.
Затраты растут с числом пикселей, октав и включением Warp. Сохранение считает полное разрешение.
