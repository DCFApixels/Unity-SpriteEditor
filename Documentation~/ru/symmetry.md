# Симметрия и бесшовное рисование

Для отражённых и повторяющихся мазков открой **Symmetry & Repeat** у Drawing-слоя:
каждый слой запоминает свою конфигурацию. Для переноса мазков через края всего холста включи
**Tiled** над превью и рисуй на любой копии — отпечаток на краю продолжается с противоположной стороны.

## Режимы симметрии, границы и отличие от тайлинга

| Режим | Настройки |
| :--- | :--- |
| Mirror | Оси X/Y, Center и Angle. При 0° X отражает по вертикальной оси, Y — по горизонтальной. |
| Horizontal / Vertical | Ряд или столбец с количеством копий. |
| Grid | Независимое количество копий по X/Y. |
| Radial | Center, количество секторов и Start Angle. |
| None | Без копий мазка. |

**Copy / Alternate Mirror** создаёт обычные копии или отражает каждую вторую в режимах повторения.
Mirror — самостоятельный режим, не дополнительное отражение поверх остальных.
Mirror поворачивается против часовой стрелки; Start Angle у Radial отсчитывается против часовой от направления влево.

**Edges → Continue** позволяет пересекать границы областей. **Clip** ограничивает мазок начальной
областью, а каждый повторённый отпечаток — его собственной областью. Активная копия остаётся под курсором.

Симметрия копирует **новые мазки**. Тайлинг трансформа повторяет **источник слоя**.
Tiled-превью повторяет **всю композицию**, не меняя размер документа/экспорта.
Кисть, карандаш и их стирание переносятся через края и при трансформе; при этом исходная рамка
трансформированного слоя по-прежнему определяет, где его пиксели могут принять мазок.
