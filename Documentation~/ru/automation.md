# Автоматизация

C# / JSON API создаёт документы, импортирует изображения, собирает слои, задаёт эффекты и рисует мазки.
Необязательный адаптер Unity Pipeline предоставляет `sprite_editor_*` через Unity CLI;
C# API работает и без него.

[Инструкция агенту](https://github.com/DCFApixels/Unity-SpriteEditor/blob/main/AGENTS.md) · [Справочник API](../AgentAPI.md) ·
[Примеры JSON](../Examples/index.md) · [История изменений](https://github.com/DCFApixels/Unity-SpriteEditor/blob/main/CHANGELOG.md)

## Безопасный рабочий цикл

1. Укажи конкретный проект Unity и проверь доступные команды через `sprite_editor_describe`.
2. Для существующего документа получи `sprite_editor_inspect`: используй ID слоёв и revision, не имена.
3. Импортируй локальное изображение, затем создай File-слой и задай Transform.
4. Проверь пакет изменений с `dryRun:true`, после этого выполни его.
5. Сохрани, отрендери и проверь результат. Проверяй `success` API отдельно от кода выхода CLI.

API использует цвета явно: режим HDR-пикеров окна не меняет запросы агента.
Выделение области в окне не ограничивает API-мазки. API v1 не редактирует код Shader FX;
имеющийся код и неподдерживаемые частичные правкой настройки сохраняются.

[Полная спецификация API](../AgentAPI.md) и JSON-примеры приведены на английском, чтобы
не дублировать контракт протокола. Руководство выше доступно на обоих языках.

Не запускай компиляцию, установку зависимостей или изменения ассетов вопреки правилам проекта.
После неопределённого ответа на запрос сначала перечитай документ: операции добавления не идемпотентны.
