# Горячие клавиши

## Документ, слои и прозрачность

| Сочетание | Действие |
| :--- | :--- |
| `Ctrl+S` | Save / Save As. |
| `Ctrl+Z` · `Ctrl+Y` / `Ctrl+Shift+Z` | Undo · Redo. |
| `↑` / `↓` | Предыдущий / следующий видимый слой. |
| `Ctrl`-клик / `Shift`-клик вне миниатюр | Переключить слой / выбрать диапазон. |
| `Ctrl+Shift`-клик | Добавить диапазон. |
| `Ctrl+E` / `Ctrl+Alt+E` | Слить выделение / создать объединённую копию. |
| `0`–`9` или numpad | Прозрачность выбранных слоёв. |

`5` — 50%, затем `7` в пределах 0,6 секунды — 57%. После паузы `7` означает 70%.
`0` — 100%, быстрое `00` — 0%, `05` — 5%. Быстрая пара отменяется одним Undo.

## Рисование, выделение и навигация

| Сочетание | Действие |
| :--- | :--- |
| `[` / `]` · `X` | Размер кисти/карандаша · смена цветов. |
| `Alt`-клик/перетаскивание с Brush, Pencil или Fill | Взять основной цвет. |
| `ПКМ` с Brush/Pencil | Временно стирать. |
| `Shift` при перетаскивании / `Shift`-клик при рисовании | Линия по оси / соединение точек. |
| `Ctrl`-клик по миниатюре/стрелке группы | Выделить альфу. |
| `Ctrl+C` / `Ctrl+Shift+C` / `Ctrl+V` | Копировать слой / композицию / вставить. |
| `Ctrl+A` / `Ctrl+D` / `Ctrl+Shift+I` | Выделить всё / снять / инвертировать область. |
| `Shift` / `Alt` / `Shift+Alt` при выделении | Добавить / вычесть / пересечь. |
| `Enter` / `Backspace` / `Escape` с лассо | Замкнуть / убрать вершину / отменить. |
| Перетаскивание с `СКМ` / колёсико | Сдвинуть вид / изменить масштаб при любом инструменте. |
| `Alt`-клик с лупой | Отдалить. |
| `Ctrl` при привязке | Отключить примагничивание. |
| `Enter` в Transform · `Escape` во время действия | Выйти из инструмента · отменить действие. |

На macOS для сохранения, выделения и Undo/Redo также работает `Cmd`.
Текстовые/числовые поля сохраняют обычный ввод. Горячие клавиши Unity приостанавливаются только при фокусе Sprite Editor.
