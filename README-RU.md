Создавай спрайты, иконки, паттерны и многослойные текстуры, не покидая Unity. Комбинируй исходные
изображения, рисуй на превью и добавляй процедурные эффекты. Редактируемая композиция и готовая
текстура сохраняются в одном ассете — отдельное изображение можно экспортировать при необходимости.

> Сохранённые текстуры и спрайты можно использовать в игре без пересчёта слоёв.

<a id="installation"></a>
## Установка

**Unity 6 (`6000.0`) или новее.** В **Window → Package Management → Package Manager**
выбери **Install package from git URL** и вставь:

```text
https://github.com/DCFApixels/Unity-SpriteEditor.git
```

Burst, Collections и Newtonsoft Json указаны в [зависимостях пакета](package.json).

<details>
<summary>Установка через manifest.json и фиксация версии</summary>

Добавь запись в объект `dependencies` файла `Packages/manifest.json`:

```json
"com.dcfa_pixels.sprite-editor": "https://github.com/DCFApixels/Unity-SpriteEditor.git"
```

URL использует основную ветку. Добавь `#<tag>` с существующим
[релизным тегом](https://github.com/DCFApixels/Unity-SpriteEditor/tags), чтобы закрепить версию.
Плашка версии показывает package.json, а не последний тег.

</details>

<a id="quick-start"></a>
## Первый документ

1. Открой **Window → Sprite Editor**, нажми **New** и задай **W / H** над превью.
2. Перетащи текстуру из Project на превью или нажми **Лист +** внизу Layers,
   чтобы создать пустой Drawing-слой.
3. Выдели слой: **Transform** (`T`) меняет его положение и размер, **Brush** (`B`) рисует на Drawing.
4. Нажми `Ctrl+S` — сохранятся редактируемый документ и результат в полном разрешении.
5. Назначь ассет в текстурное поле или раскрой его в Project и используй **Output Sprite**.

Двойной клик по сохранённой текстуре, спрайту или вложенному документу открывает редактор.
Также работают **Assets → Open in Sprite Editor** и кнопка в инспекторе документа.

<a id="workspace"></a>
### Как устроено окно

Превью слева; **Layer Settings** и **Layers** справа. Выдели слой, чтобы увидеть его настройки.
Разделители меняют размеры панелей; правая сохраняет ширину при изменении размера окна.
На левой панели выбирается инструмент, а над превью появляются его настройки.

Перетаскивание с `СКМ` сдвигает вид, колёсико меняет масштаб — при любом инструменте.
**Fit** вписывает холст целиком; **100%** показывает один пиксель изображения на одну единицу интерфейса.

<details>
<summary>Инструменты, отдельные окна Properties и личные настройки</summary>

| Инструмент | Клавиша | Назначение |
| :--- | :---: | :--- |
| No Tool | `V` | Просмотр без маркеров редактирования. |
| Transform | `T` | Перемещение, масштабирование и вращение слоя, кроме группы. |
| Rectangle Select | `M` | Прямоугольное выделение. |
| Polygonal Lasso | `L` | Многоугольное выделение кликами по вершинам. |
| Brush / Pencil | `B` / `P` | Мягкая кисть / чёткое пиксельное рисование. |
| Fill | `G` | Заливка связанной области или всех подходящих цветов. |
| Zoom | `Z` | Клик приближает, `Alt`-клик отдаляет, перетаскивание вписывает область. |

Лупой можно захватывать и пустое пространство. Навигация меняет только вид;
другой документ открывается в Fit. Последний инструмент запоминается.
No Tool оставляет строку настроек пустой, не сдвигая холст.

Каждый вызов **⋮ слоя → Properties** открывает отдельное окно; **FX** открывает редактор модификаторов.
**Меню ⋮ вкладки окна → User Settings…** задаёт цвета шахматки, размер клетки и цвет невалидных пикселей.
Это настройки пользователя, а не изменения документа.

**Reset Sprite Editor Settings…** в том же меню после подтверждения сбрасывает расположение панелей
и настройки инструментов/просмотра во всех открытых окнах. Сброс не имеет Undo, но не удаляет
документы, несохранённую работу и ассеты, не меняет настройки слоёв и расположение вкладок Unity.

</details>

<a id="layers"></a>
## 1. Собрать и расположить слои

**Верхний слой находится в начале списка.** Последний выбранный слой становится активным:
с ним работают рисование, трансформ и Layer Settings. Клик выбирает строку; `Ctrl` переключает
выделение отдельных строк, `Shift` выбирает диапазон, `↑` / `↓` перемещают выбор по видимым строкам.

Начни с **File**, **Drawing**, **Color Fill**, **Gradient** или **Noise** через **+**.
Текстуры из Project можно сбрасывать между строками и внутрь групп; сброс на превью добавляет их наверх.
Первая текстура в пустом File-слое автоматически получает **Original Aspect**.
Исходные текстуры не изменяются.

Тяни за фон или миниатюру выбранной строки, чтобы переместить выделение. **Папка** группирует его.
Прозрачность и Blend меняются прямо в строке: правка любого из этих полей у выбранного слоя
применяется ко всем выбранным слоям.

<details>
<summary>Кнопки нижнего тулбара, группы, дублирование и имена</summary>

| Иконка | Клик | Сброс выделенных слоёв |
| :--- | :--- | :--- |
| **+** | Выбрать тип нового слоя. | Дублировать выделение. |
| **Лист +** | Создать Drawing над активным слоем. | Слить в Drawing-копию, сохранив оригиналы. |
| **Папка** | Сгруппировать выделение. | Сгруппировать перетаскиваемые слои. |
| **Корзина** | Удалить выделение. | Удалить перетаскиваемые слои. |

**⋮** или правый клик открывает меню строки. Поддерживаемые действия применяются ко всему выделению.
Выбранная группа включает потомков один раз. **Duplicate** создаёт независимые пиксели Drawing
и встроенные FX; внешние ассеты остаются ссылками. Цели внутри копируемого набора следуют за копиями.

Группы по умолчанию используют **Pass Through**: дочерние слои смешиваются с общим стеком.
Другой Blend изолирует группу; её прозрачность влияет на общий результат.
Трансформы и модификаторы групп пока не поддерживаются. Глаз в заголовке таблицы показывает все слои и группы.

У каждого типа свой растущий счётчик. Drawing называется `Layer n`;
остальные — по типу, например `File n`, `Noise n`, `Group n`.
Копии получают суффикс ` Copy n` с отдельным общим счётчиком. Номера удалённых слоёв не переиспользуются.

</details>

<details>
<summary>Noise: seed, масштаб деталей и вывод цвета/данных</summary>

Noise генерирует OpenSimplex2, OpenSimplex2S, Perlin, Value, Value Cubic или Cellular на GPU.
Выбери Seed, настрой Scale/Offset, добавь фракталы или Domain Warp. Чем больше Scale, тем мельче детали;
масштаб измеряется по короткой стороне холста. Перетаскивай подписи числовых полей или слайдеры для обновления превью.

**Color Values** выводит градации серого для просмотра, **Linear Data** сохраняет сырые 0–1 для масок,
карт высот и упаковки каналов. В RGB одно и то же значение, альфа равна 1. Хранятся параметры,
не снимки пикселей; экспорт использует те же координаты/seed в полном разрешении.
Tiled-превью повторяет результат, но сам Noise пока не является бесшовным.

</details>

<a id="transform"></a>
### Разместить изображение

Выбери **Transform** (`T`): тяни рамку для перемещения, края и углы для изменения размера,
круглый маркер для вращения. Для числового ввода раскрой **Transform** в Layer Settings.
**Original Aspect** возвращает пропорции источника внутри рамки; **Reset** сбрасывает трансформ.

<details>
<summary>Пивот, привязка, тайлинг и фильтрация</summary>

- Перемещай золотой пивот, не сдвигая изображение. Он притягивается к углам, серединам сторон и центру.
  `Ctrl` отключает привязку; пивот можно вынести за рамку.
- `Shift` ограничивает движение осью, сохраняет пропорции размера или задаёт шаг вращения 15°.
  `Escape` отменяет перетаскивание, `T` / `Enter` выходит из Transform. Одно перетаскивание — один Undo.
- **Tiling:** Clip оставляет за рамкой прозрачность; Repeat повторяет источник;
  Mirror чередует отражённые тайлы; Source наследует режимы текстуры, в том числе отдельные U/V.
- **Filter:** Source наследует настройку текстуры, Point сохраняет пиксельные края, Bilinear сглаживает,
  Trilinear использует существующие mip-карты. Без них он работает как Bilinear.
  Для процедурных слоёв Source использует Bilinear. Filter сохраняется при Reset.
- Position измеряется в пикселях холста, Pivot — нормализованные координаты, Scale — множитель,
  Rotation — градусы. Original Aspect уменьшает одну ось, сохраняя центр изображения, пивот,
  вращение, отражение и тайлинг.

Тайлинг трансформа повторяет источник слоя. Это не то же самое, что повторение кисти или Tiled-превью.

</details>

<details>
<summary>Слить слои или конвертировать их в Drawing</summary>

`Ctrl+E` заменяет выделение одним Drawing-слоем; `Ctrl+Alt+E` создаёт объединённую копию,
оставляя оригиналы включёнными. Обе команды есть в меню строки. Видимое содержимое,
трансформы и эффекты запекаются в полном разрешении холста; трансформ результата сбрасывается.
Слияние отменяется одним Undo. При частичном слиянии смешивание с невыделенными слоями может измениться.

**Convert to Drawing** работает с любым слоем, в том числе уже рисовальным:

| Режим | Результат |
| :--- | :--- |
| **Keep Transform** | Растеризовать источник, оставив трансформ редактируемым. |
| **Apply Transform** | Запечь трансформ/тайлинг в пиксели холста, сбросить Transform и включить Clip. |

Одиночный слой сохраняет ID, имя, позицию, прозрачность, смешивание и живые модификаторы.
Группа объединяет видимых потомков с Normal и прозрачностью 1. Для неё нужно подтверждение:
внешнее смешивание может измениться, а цели, ссылающиеся на удалённых потомков, потеряются.
Ссылки на саму группу остаются рабочими. Конвертация поддерживает Undo/Redo.

</details>

<a id="painting"></a>
## 2. Рисовать, заливать и выделять области

Выбери **Drawing** и рисуй на превью, видя всю композицию. **Brush** (`B`) даёт мягкие края,
**Pencil** (`P`) — чёткие пиксели с круглым, квадратным или ромбовым наконечником.

- **Size**, **Hard** и **Step** задают диаметр, жёсткость и шаг отпечатков кисти.
  Потяни за Size/Step или меняй размер клавишами `[` / `]`.
- `X` меняет местами два цвета. Зажми `Alt` и кликни или проведи мышью, чтобы взять цвет из композиции.
- `ЛКМ` использует выбранный режим рисования/ластика; `ПКМ` временно стирает.
- `Shift` при перетаскивании рисует вдоль оси; `Shift`-клик соединяет новую точку с предыдущей.

Настройки инструментов общие и **не добавляют шагов Undo**. Симметрия и трансформ принадлежат слою.
Клик инструментом рисования по другому типу слоя предлагает конвертацию; сам этот клик не рисует.

<details>
<summary>Шаг кисти, превью карандаша и прямые линии</summary>

Step измеряется в процентах от диаметра. У Pencil свой размер (изначально 1 px), нет жёсткости
и шага: линия непрерывно следует пиксельной сетке. Горячие клавиши размера дают шаг 1 px
до 20 px, затем — примерно 10%.

Pencil временно включает Point-фильтрацию и полное разрешение превью, фиксируя Live Quality на 100%.
При смене инструмента возвращается сохранённое качество. При близком зуме контур курсора следует границам пикселей.

Для новой линии вдоль оси кликни без `Shift`, затем зажми его и тяни.
Последовательные `Shift`-клики создают соединённые отрезки; стирание, шаг и повторение применяются тоже.
Undo/Redo, очистка слоя и смена документа сбрасывают точку соединения.

Временная пипетка работает с Brush, Pencil и Fill. Она берёт цвет и альфу из полной композиции,
не учитывая экспозицию превью, фильтрацию каналов, шахматку и подсветку Debug.

</details>

### Залить область

Выбери **Fill** (`G`) и кликни, чтобы записать основной цвет в активный Drawing-слой.
**All Layers** определяет, брать границы из этого слоя или из всей видимой композиции.
**Contiguous** выбирает связанную область либо все подходящие цвета.

<details>
<summary>Настройки и ограничения заливки</summary>

| Настройка | Назначение | По умолчанию |
| :--- | :--- | :--- |
| All Layers | Выборка по всей композиции вместо исходных пикселей слоя. | Выключен |
| Contiguous | Только связанная область под кликом. | Включён |
| Tolerance | Сходство цвета/альфы, 0–255. | 32 |
| Antialias | Смягчение границы. | Включён |
| Expand (px) | Расширение под контур на 0–32 пикселя источника. | 0 |

Заливка всегда пишет в активный Drawing, а не во все слои выборки. Одна заливка — один Undo.
Она редактирует основную область источника и не повторяется через симметрию кисти.
Для отображаемых копий за этой областью сначала используй **Convert to Drawing → Apply Transform**.
All Layers проецируется в сетку источника; слой размером с холст без трансформа даёт границы в пикселях холста.
Выборка остаётся полноразмерной независимо от Live Quality; лимит — 16 777 216 пикселей на изображение.

</details>

### Ограничить редактируемую область

Используй **Rectangle Select** (`M`) или **Polygonal Lasso** (`L`).
Выделение ограничивает рисование, стирание и заливку. `Ctrl`-клик по миниатюре слоя или стрелке
группы выделяет её альфу; `Ctrl+D` снимает выделение.

`Ctrl+C` копирует выбранную область активного слоя, `Ctrl+Shift+C` — видимой композиции.
`Ctrl+V` вставляет её на **новый Drawing-слой**.

<details>
<summary>Лассо, операции выделения и буфер обмена</summary>

Задавай вершины лассо кликами; заверши через `Enter`, двойной клик, первую вершину или **Close**.
`Backspace` / `ПКМ` убирает вершину, `Escape` отменяет незавершённую фигуру.
В шапке есть Replace/Add/Subtract/Intersect; `Shift` / `Alt` / `Shift+Alt` добавляет/вычитает/пересекает.
`Ctrl+A` выделяет всё, `Ctrl+Shift+I` инвертирует область.

Выделение сохраняется при смене инструмента/слоя, но очищается при смене документа, изменении размера холста,
закрытии окна или перезагрузке скриптов. Это временное состояние, не история Undo; оно не ограничивает
штрихи через API агентов. Пустое активное выделение блокирует рисование. Лимит — 16 777 216 пикселей холста.

Выделение по альфе учитывает трансформ, FX, Swizzle и обтравку, но игнорирует общую видимость/прозрачность
выбранного слоя. Настройки дочерних слоёв внутри группы сохраняют влияние.

Буфер внутренний для Sprite Editor и общий между его окнами до перезагрузки скриптов или выхода.
Без выделения копируется весь холст. Вставка сохраняет позицию на равном по размеру холсте;
на другом — центрирует и обрезает область. Настройки превью на копирование не влияют.

</details>

<a id="symmetry"></a>
### Рисовать паттерны и бесшовные текстуры

Для отражённых и повторяющихся мазков открой **Symmetry & Repeat** у Drawing-слоя:
каждый слой запоминает свою конфигурацию. Для переноса мазков через края всего холста включи
**Tiled** над превью и рисуй на любой копии — отпечаток на краю продолжается с противоположной стороны.

<details>
<summary>Режимы симметрии, границы и отличие от тайлинга</summary>

| Режим | Настройки |
| :--- | :--- |
| Mirror | Оси X/Y, Center и Angle. При 0° X отражает по вертикальной оси, Y — по горизонтальной. |
| Horizontal / Vertical | Ряд или столбец с количеством копий. |
| Grid | Независимое количество копий по X/Y. |
| Radial | Center, количество секторов и Start Angle. |
| None | Без копий мазка. |

**Copy / Alternate Mirror** создаёт обычные копии или отражает каждую вторую в режимах повторения.
Mirror — самостоятельный режим, не дополнительное отражение поверх остальных.
Mirror поворачивается против часовой стрелки; Start Angle у Radial отсчитывается против часовой от направления влево.

**Edges → Continue** позволяет пересекать границы областей. **Clip** ограничивает мазок начальной
областью, а каждый повторённый отпечаток — его собственной областью. Активная копия остаётся под курсором.

Симметрия копирует **новые мазки**. Тайлинг трансформа повторяет **источник слоя**.
Tiled-превью повторяет **всю композицию**, не меняя размер документа/экспорта.
Кисть, карандаш и их стирание переносятся через края и при трансформе; при этом исходная рамка
трансформированного слоя по-прежнему определяет, где его пиксели могут принять мазок.

</details>

<a id="effects"></a>
## 3. Добавить эффекты и ограничить их форму

Через **+** добавь слой эффекта над источником:

| Задача | Слой | С чего начать |
| :--- | :--- | :--- |
| Обвести форму | Outline | Ширина, мягкость и положение. |
| Построить поле расстояний | SDF | Канал, порог и расстояние. |
| Получить карту нормалей | Normal Map | Height Map или Texture; сначала настройки Simple. |
| Размыть изображение | Gaussian Blur | Radius. |
| Создать след движения | Motion Blur | Длина/угол Linear либо дуга/центр Circular. |

**Previous** — следующий сосед ниже эффекта; **Specific** — конкретный слой или группа.
Перетащи слой на Target для назначения. Из перетаскиваемого выделения берётся активный слой.
Скрытый источник доступен эффекту; внутри группы скрытые дети по-прежнему исключены.
Эффект видит собственное изолированное содержимое группы, хотя в общей композиции она может остаться Pass Through.

<details>
<summary>Настройки размытия и качество во время редактирования</summary>

- **Gaussian Blur:** Radius — 0–256 пикселей исходного холста, по умолчанию 8; ноль отключает размытие.
- **Motion Blur:** Linear использует Distance (0–512 px) и Angle. Circular — Arc (0–360°)
  и нормализованный Center: `(0.5, 0.5)` в середине. Circular — вращение, не приближение.
  Direction: Centered/Forward/Backward; Forward следует углу либо идёт против часовой стрелки.
- **Strength** у Motion Blur — 0–400%, по умолчанию 100%. До 100% смешивает с исходником,
  выше — делает полупрозрачный след плотнее, не меняя длину и яркость цвета.
  Полностью непрозрачные пиксели выше 100% не меняются.
- **Edges:** Transparent, Clamp, Repeat или Mirror, независимо от Tiled.
  Оба эффекта учитывают альфу при фильтрации цвета; HDR Color Range сохраняет интенсивности выше 1.

Сильное размытие использует облегчённое превью и уточняется после редактирования.
Сохранение и экспорт используют полное качество. Кеш ограничен и отделён от Undo;
первый рендер большого изображения всё равно может быть дорогим, а длинная круговая дуга — давать отдельные следы на мелких деталях.

[Рендер и кеш Gaussian](Documentation~/GaussianBlur.md) · [Подробности Motion Blur](Documentation~/MotionBlur.md)

</details>

<details>
<summary>Источники Outline/SDF и вывод Normal Map</summary>

Outline/SDF получают от групп grayscale-покрытие; Normal Map и размытия — RGBA.
Есть точный Euclidean EDT, приближённый Euclidean, Manhattan и Chebyshev.
Цели с самоссылками и циклическими зависимостями отклоняются.

Normal Map **Height Map** использует выбранный канал высоты; **Texture** оценивает рельеф по деталям изображения.
**Output → Height** помогает настроить восстановление, затем верни Normal.
Advanced раскрывает фильтрацию, диапазоны деталей, удаление освещения, уровни, ориентацию и кодирование.
Возврат в Simple не сбрасывает эти значения.

Для рабочей карты нормалей оставь Normal, прозрачность 1 и исходный Swizzle.
Смешивание не нормализует векторы; Transform перемещает изображение, не переориентируя нормали.
Packed Color подходит для PNG/TGA/PSD, Linear Data — для линейных EXR/Texture2D.
Экспортированный PNG/TGA импортируй как **Normal Map**, без преобразования из grayscale.

[Параметры Normal Map](Documentation~/AgentAPI.md#normal-map-settings)

</details>

### Ограничить слой формой нижнего

Включи **Clipping Mask** в меню строки или нажми `Alt` на границе над базовым слоем.
Несколько обтравочных слоёв подряд используют первого соседа без обтравки под ними, внутри той же группы.
Они сохраняют цвета и эффекты, но не расширяют альфу базы.

<details>
<summary>Обтравка, смешивание групп и режимы наложения</summary>

Скрытая, прозрачная или отсутствующая база скрывает цепочку. Прозрачность базы применяется к общему результату один раз.
Группы в обтравке изолируются на время участия в ней. Обтравка поддерживает Undo/Redo,
дублирование, API агентов и флаги PSD; слияние запекает её.

Обычные режимы смешивают RGB в пересечении по правилу source-over для альфы.
**Overwrite** заменяет полный RGBA; прозрачность слоя смешивает старые и новые пиксели.
**None** не меняет композицию.

Normal · Add · Subtract · Multiply · Divide · Screen · Overlay · Darken · Lighten ·
Color Dodge · Color Burn · Linear Dodge (Add) · Linear Burn · Linear Light ·
Linear Light Add/Sub · Vivid Light · Pin Light · Hard Mix · Hard Light · Soft Light ·
Difference · Exclusion · Negation · None · Overwrite.

</details>

### Написать свой эффект

Нажми **+ Shader FX** в настройках слоя, напиши `ApplyFX` и нажми **Apply**.
Код и параметры могут храниться прямо в документе. Чтобы обработать уже собранную композицию
ниже определённой позиции, добавь отдельный слой **Shader Processor**.

<details>
<summary>Shader FX: первый фрагмент, параметры и подключение библиотек</summary>

Добавь параметр **Float** с именем `_Amount` и примени пример:

```hlsl
float4 ApplyFX(float2 uv, float4 color)
{
    return float4(lerp(color.rgb, 1.0 - color.rgb, saturate(_Amount)), color.a);
}
```

Параметры: Float, Color, Vector и Texture2D; их uniform-переменные генерируются автоматически.
Код и объявления остаются черновиком до Apply. При ошибке работает последний успешный вариант.
Undo/Redo восстанавливает код, курсор и выделение; восстановленный код тоже нужно применить.

`SampleInput(uv)` читает слой после предыдущих модификаторов. Возвращай straight RGBA:
прозрачность/смешивание применяются позже. Встроены `_MainTex`, `_MainTex_TexelSize`, `_InputSize`,
`_CanvasSize` (ширина, высота, 1/ширина, 1/высота) и `_PreviewScale`.
Не объявляй сгенерированные uniform-переменные повторно.

Стандартный `#include` поддерживает пути проекта/пакета и относительные пути.
Относительные начинаются от папки документа/FX, до первого сохранения — от Assets.
После правки библиотеки снова нажми Apply; после Save As в другую папку проверь пути.
Библиотеки должны подходить для этого окружения фрагментного шейдера.

**+ Reference** подключает внешний FX для совместного использования; **Embed** делает независимую копию внутри документа.
Save As и дублирование слоёв независимо копируют встроенные FX. Эффекты идут по порядку после Transform;
изменение значений параметров не генерирует шейдеры заново.

</details>

<details>
<summary>Shader Processor: обработать нижний стек вместо одного слоя</summary>

Processor использует тот же ApplyFX/SampleInput, но получает нижнюю композицию.
При Normal Opacity смешивает исходный и обработанный RGBA; 100% заменяет источник.
Другие режимы смешивают его с результатом. Оба диапазона по умолчанию HDR; скрытие Processor отключает обработку.

В Pass Through он видит и внешний фон; изолированная группа ограничивает его своими детьми.
Отдельное превью и растеризация собирают нижних соседей на прозрачном фоне.
Processor разделяет цепочки обтравки, не служит участником или базой.
PSD запекает композицию, сохраняя исходные слои в скрытой папке Source Layers.

</details>

<a id="preview"></a>
## 4. Проверить результат

Внизу превью находятся качество, каналы, экспозиция и диагностика.
**Live Quality** меняет разрешение во время рисования (12,5–100%, по умолчанию 80%), но не сохранённые пиксели.
**EV** меняет экспозицию просмотра; кнопка-жучок показывает невалидные числовые значения.

> [!IMPORTANT]
> Кнопки **R / G / B / A** — ещё и **маска рисования**.
> Отключённые RGB-каналы пишут `0` в новых мазках/заливках; при выключенном A следа не остаётся.
> Стирание игнорирует маску. Существующие пиксели и экспортируемые каналы от переключения не меняются.

<details>
<summary>Просмотр каналов, HDR-цвета и диапазоны слоя</summary>

Один RGB-канал показывается в градациях серого, с прозрачностью при включённом A.
Только A показывает непрозрачную grayscale-альфу. Два или три RGB сохраняют свои цвета;
выключенный A скрывает прозрачность.

Кнопка **HDR** внизу меняет пикеры цвета/градиента, а не сохранённые цвета или диапазоны слоёв.
Без HDR цвет показывается и рисует без сохранённой интенсивности; обратное переключение возвращает её.
Редактирование цвета заменяет сохранённое значение.

В **Layer Settings → Color & Blending** Color Range и Blend Range независимо управляют ограниченным
и расширенным диапазоном. Список в заголовке меняет оба; пустое значение означает, что они различаются.
Композиция рассчитывается в линейном HDR. Drawing начинает с 8 бит и повышает хранение до half-float;
возврат в Standard не удаляет сохранённый HDR. Для этого есть явная команда **Convert to 8-bit**.

[HDR, хранение и группы](Documentation~/HDR.md)

</details>

<details>
<summary>Упаковка данных через Swizzle и Assign Channels</summary>

**Swizzle** переназначает RGBA любого слоя/группы после FX, перед диапазонами и смешиванием:
`R`, `G`, `B`, `A`, `1-R`, `1-G`, `1-B`, `1-A`, `0`, `1`, `R * A`, `G * A`, `B * A`.
Умножение использует входную альфу. Изменённый Swizzle группы изолирует её содержимое.

**Меню строки → Assign Channels** настраивает выбранные слои сверху вниз по дереву:

- **1–3 слоя:** `R * A` каждого идёт в R, G или B; остальные RGB — нули, A — 1.
  Верхние выбранные слои получают Add; наложение нижнего и прозрачность всех слоёв сохраняются.
- **4 слоя:** `R * A` каждого идёт в R, G, B или A; остальные каналы обнуляются.
  Меняется только Swizzle. У RGB-слоёв нулевая альфа, обычное смешивание пропускает их:
  один этот пресет **не собирает** готовую четырёхканальную текстуру.

При выборе более четырёх слоёв команда неактивна. Она не сливает, не переставляет и не переносит слои;
группы, окружающее содержимое и обтравка продолжают влиять на результат. Это один шаг Undo.

</details>

### Посмотреть постобработку игры

Включи **Post FX** внизу превью и открой панель стрелочкой: выбери Scene View, Game Camera
или Volume Profile. Сейчас необязательная интеграция поддерживает **URP 17.x с Universal Renderer**.

Post FX действует только на просмотр: рисование, выборка цвета, сохранение и экспорт используют
исходную композицию. Сам редактор и Shader Processor не требуют URP.

<details>
<summary>Post FX: источники, фон и глубина по альфе</summary>

- **Scene View** наследует включение постэффектов и Volume активного окна сцены.
- **Game Camera** берёт настройки/Volume выбранной камеры; пустое поле использует MainCamera.
- **Profile** использует Volume Profile с ручными настройками камеры.
- **Background:** Solid Color или Checkerboard — непрозрачная подложка до обработки.
  Цвет фона и внешний вид шахматки общие с User Settings.
- **Depth:** Solid — постоянная глубина, Alpha Height — рельеф по альфе, Alpha Mask отправляет
  пиксели ниже Threshold на дальнюю плоскость. Источник — исходная альфа, не фон и не просмотр каналов.
- **Link to Zoom** связывает дистанцию с зумом. **Animate** обновляет анимацию до 8 раз в секунду.
  Закрытие панели не отключает Post FX.

</details>

<details>
<summary>Post FX: Renderer Features и ограничения совместимости</summary>

Синтетическая непрозрачная поверхность проходит через активные фичи выбранного Universal Renderer,
включая Full Screen Pass и SSAO. Depth/Depth Normals описывают альфа-рельеф;
дополнительные проходы цвета, глубины и нормалей запрашиваются по необходимости.
Отключение Post FX освобождает ресурсы редактора.

Это не копия сцены: геометрия, освещение и стек камер не рисуются. Фичи должны объявлять входы
и поддерживать рендер в текстуру; фильтры объектов могут исключать поверхность.
Фичи с историей движения или буферами материалов не гарантируются.
TAA, Motion Blur пайплайна и временная фильтрация AO пропускаются.
STP и неподдерживаемые пайплайны/рендереры показывают исходное превью с пояснением.
Камеры, профили и настройки проекта не меняются.

</details>

<a id="saving"></a>
## 5. Сохранить, открыть снова и использовать текстуру

`Ctrl+S` сохраняет документ или открывает Save As в первый раз.
**Save** обновляет его без диалога и неактивен, если сохранять нечего;
**Save As** создаёт независимую копию. При закрытии изменённого документа есть **Save / Discard / Cancel**.

В сохранённом `.asset` уже находятся полноразмерная **Texture2D**, **Output Sprite**
и документ со слоями. Назначай главный ассет в текстурное поле или раскрой его для использования спрайта.
Отдельный экспорт не обязателен.

> [!IMPORTANT]
> Unity использует результат **последнего явного сохранения через Sprite Editor**.
> После Undo/Redo, изменения FX или внешних исходных текстур сохрани документ снова.

<a id="export"></a>
### Экспортировать отдельный файл

| Формат | Для чего |
| :--- | :--- |
| **PNG / TGA** | Цветное изображение с прозрачностью. |
| **JPEG** | Непрозрачное изображение; белый фон, качество 95. |
| **EXR** | Линейный HDR RGB + альфа. |
| **PSD** | Обмен многослойным изображением, с группами и сведённым результатом. |
| **Texture2D (.asset)** | Самостоятельная текстура Unity без документа со слоями. |

<details>
<summary>Ссылки на результат, HDR-экспорт и компромиссы PSD</summary>

При повторном сохранении ссылки на результат остаются рабочими, в том числе после изменения размера холста.
Пиксели Drawing и встроенные FX находятся внутри документа; внешние текстуры и ссылочные FX остаются связаны.
Миниатюра Project показывает сохранённые пиксели. У Output Sprite центральный пивот, прямоугольная геометрия и 100 PPU.

EXR и Texture2D сохраняют HDR; PNG/JPEG/TGA/PSD ограничивают экспортируемую копию.
Изображения внутри Assets импортируются как одиночные Sprite, кроме EXR — он становится линейной текстурой.
Замена самостоятельного Texture2D требует подтверждения и сохраняет ссылки.

PSD сохраняет имена, порядок, видимость, прозрачность и поддерживаемое наложение.
Совместимые заливки, градиенты и обводки Outline остаются редактируемыми;
остальные эффекты растрируются, неподдерживаемые бленды заменяются приближёнными.
Пояснения экспорта описывают компромиссы по слоям.
Сохраняй исходный документ: PSD не хранит живые цели эффектов и шейдерный код.

[Подробности экспорта PSD](Documentation~/PsdExport.md)

</details>

| `Enter` в Transform · `Escape` во время действия | Выйти из инструмента · отменить действие. |

</details>

На macOS для сохранения, выделения и Undo/Redo также работает `Cmd`.
Текстовые/числовые поля сохраняют обычный ввод. Горячие клавиши Unity приостанавливаются только при фокусе Sprite Editor.

## Автоматизировать тот же процесс

C# / JSON API создаёт документы, импортирует изображения, собирает слои, задаёт эффекты и рисует мазки.
Необязательный адаптер Unity Pipeline предоставляет `sprite_editor_*` через Unity CLI;
C# API работает и без него.
