Создавай спрайты, иконки, паттерны и многослойные текстуры, не покидая редактор. Рисуй прямо
на превью, организуй слои во вложенные группы, добавляй Outline/SDF и сохраняй
редактируемую композицию отдельно от готового изображения.

> [!NOTE]
> Это инструмент **только для Unity Editor**, построенный на UI Toolkit, а не компонент
> рисования во время выполнения игры.

## Возможности

| Экспорт | PNG, JPEG, TGA, EXR и нативный Texture2D-ассет Unity. |

<a id="installation"></a>
## Установка

**Требуется Unity 6 (`6000.0`) или новее.** Burst и Collections указаны в зависимостях пакета.

Открой **Window → Package Management → Package Manager**, выбери **Install package from git URL**
и вставь:

```text
https://github.com/DCFApixels/Unity-SpriteEditor.git
```

<details>
<summary>Установка через manifest.json или фиксация версии</summary>

Добавь запись в объект `dependencies` файла `Packages/manifest.json`:

```json
"com.dcfa_pixels.sprite-editor": "https://github.com/DCFApixels/Unity-SpriteEditor.git"
```

Этот URL использует основную ветку. Чтобы зафиксировать релиз, добавь к адресу существующий
тег из [списка тегов](https://github.com/DCFApixels/Unity-SpriteEditor/tags).
Плашка версии читает [`package.json`](package.json), а не номер последнего релизного тега.

</details>

<a id="quick-start"></a>
## Быстрый старт

1. Открой **Window → Sprite Editor** и нажми **New**.
2. Задай размер холста через **Canvas → W / H** над превью.
3. Кнопкой **+** внизу списка Layers добавь **Drawing Layer**.
4. Выдели слой и рисуй на превью. Настройки кисти находятся в его шапке.
5. Нажми `Ctrl+S`, чтобы сохранить слои и встроенную итоговую текстуру.
6. Перетащи сохранённый ассет в текстурное поле или раскрой его в Project и используй **Output Sprite**.
   **Export** нужен только для отдельного файла изображения.

> [!TIP]
> Двойной клик по текстуре, спрайту или документу со слоями в Project открывает Sprite Editor.
> Также работает **Assets → Open in Sprite Editor**; у вложенного документа сохранена кнопка в инспекторе.

<a id="workspace"></a>
## Рабочее пространство и сохранение

Общая шапка окна:

**New → поле документа → Save → Save As → Export**

- **Save** сохраняет в текущий ассет без диалога. Для нового документа кнопка неактивна.
- **Save As** создаёт отдельный редактируемый документ.
- `Ctrl+S` сохраняет существующий ассет или открывает Save As для нового документа.
- **Export** записывает итоговое изображение, а не дерево слоёв.

**Использование без экспорта.** Save / Save As записывает Texture2D полного разрешения
и **Output Sprite** в тот же `.asset`, что и редактируемые слои. Текстура становится главным
объектом файла с обычной миниатюрой изображения в Project. Её можно назначить материалам,
RawImage и полям Texture2D. Раскрой ассет, чтобы назначить Output Sprite в SpriteRenderer
или UI Image: у него центральный пивот, прямоугольная геометрия и 100 пикселей на юнит.

Повторное сохранение обновляет существующие выходные объекты, в том числе при изменении
размера холста, сохраняя ссылки. Save As создаёт независимые результаты. Старые документы
получают эту возможность при следующем Save в Sprite Editor; массовой конвертации нет.
В инспекторе вложенного документа есть **Save & Update Output** и сохранённое превью.
Результат соответствует последнему явному сохранению через Sprite Editor, а не незавершённым
правкам: после Undo/Redo или изменения внешних текстур сохрани документ снова.
Миниатюры используют готовые пиксели, не пересчитывая слои. Для использования результата
во время игры рендер слоёв не требуется.

**Превью находится слева**, настройки активного слоя и список слоёв — справа.
Вертикальный разделитель меняет ширину правой панели; при изменении размера окна она сохраняется.
Правая панель дополнительно разделена по высоте, у обоих её сегментов независимая прокрутка.

Настройки следуют за активным слоем. Раздел **Transform** изначально свёрнут; настройки кисти
появляются при выборе Drawing Layer. Каждый вызов **⋮ → Properties** открывает отдельное окно.
Пункт **FX** находится в том же меню.

В **меню ⋮ вкладки окна → Reset Sprite Editor Settings…** доступен сброс размеров панелей,
прокрутки, выделения, раскрытия разделов, режима инструмента превью и Live Quality с подтверждением.
Сброс действует на все открытые окна Sprite Editor. Документы, включая несохранённые, настройки
слоёв и кистей, ассеты, настройки Unity и расположение вкладок сохраняются. Сам сброс не имеет Undo.

<a id="layers"></a>
## Слои и группы

**Типы слоёв:** File · Drawing · Color Fill · Gradient · Outline · SDF · Group.

Перетащи один или несколько **Texture2D-ассетов из Project** в Layers, чтобы создать File-слои.
Можно сбросить их между строками, внутрь группы или в пустую область списка. Новые слои
выделяются вместе, последний становится активным; весь сброс отменяется одним Undo.
Сброс текстур на **Preview** добавляет их в самый верх корневого списка Layers, вне групп.
Исходные ассеты не изменяются. При назначении текстуры пустому File-слою автоматически
применяется **Original Aspect**; замена уже назначенной текстуры не меняет Transform.

Список отображается сверху вниз; отрисовка идёт снизу вверх.
Вложенные группы работают в режиме **pass-through**: дочерние слои смешиваются с общей
композицией без отдельной цветовой композиции группы.

| Выделение | Результат |
| :--- | :--- |
| Клик | Выделить один слой. |
| `Ctrl`-клик | Добавить слой в выделение или убрать из него. |
| `Shift`-клик | Выделить диапазон видимых строк. |
| `Ctrl+Shift`-клик | Добавить диапазон к текущему выделению. |

**Последний выбранный слой становится активным**: он отмечен более яркой заливкой и тонкой
голубой обводкой. Инспектор, рисование и визуальный трансформ работают с ним, а не со всем выделением.

В нижнем тулбаре находятся добавление, группировка и удаление. Потяни за хваталку выделенного
слоя, чтобы переместить всё выделение; сброс в центр группы перемещает слои внутрь неё.
Сброс на **папку** группирует слои, на **корзину** — удаляет, с отменой одним Undo.
Выделенная группа переносит своих потомков только один раз.

Пункт **⋮ → Duplicate** копирует слой или группу целиком. Сброс выделения на **+** дублирует
его с отменой одним Undo. Копии появляются над оригиналами и выделяются; пиксели Drawing и
встроенные Shader FX независимы, внешние ассеты остаются ссылками. Цели Outline/SDF внутри
копируемого набора перенаправляются на копии. Если источник Previous больше не находится
рядом, копия эффекта явно ссылается на него, сохраняя результат.

Меню строки и встроенные поля действуют на эту строку. Автоматические имена используют два
независимых счётчика документа: `Layer 1…` и `Group 1…`. Номера удалённых слоёв не переиспользуются.

> [!IMPORTANT]
> У групп пока нет собственной прозрачности, режима смешивания, трансформа и FX.
> Видимость группы переключается; Outline/SDF могут использовать её как источник.

<details>
<summary>Конвертация любого слоя в Drawing / применение трансформа</summary>

Используй **⋮ → Convert to Drawing**, в том числе для уже рисовального слоя.

| Режим | Результат |
| :--- | :--- |
| **Keep Transform** | Растеризовать источник, оставив Transform редактируемым. |
| **Apply Transform** | Запечь текущий Transform и тайлинг в пиксели полного разрешения, затем сбросить Transform и вернуть Clip. |

Новый слой сохраняет ID, имя, положение в списке, видимость, прозрачность, режим смешивания
и FX. Модификаторы остаются редактируемыми. У Drawing сохраняются также кисть и настройки
повторения. Outline/SDF превращаются в статичное изображение. При применении трансформа
пиксели за пределами холста обрезаются.

Группа композируется на прозрачный фон с учётом видимых потомков, их трансформов и FX.
Результат использует Normal, прозрачность 1 и сброшенный Transform, поэтому оба режима
конвертации группы дают одинаковый результат.

Перед конвертацией группы появляется подтверждение: взаимодействие pass-through с внешними
слоями может измениться, а эффекты, направленные на удалённых потомков, потеряют источник.
Ссылки на сам конвертируемый слой сохраняются. Конвертация и пиксельные текстуры поддерживают Undo/Redo.

</details>

<a id="painting"></a>
## Рисование и повторение

Кнопки **R / G / B / A** в footer превью управляют отображением каналов и маской цвета кисти.
Отключённые RGB-компоненты рисуются со значением `0`; при выключенном A кисть не оставляет следа.
Выбранные цвета кисти не меняются, ластик игнорирует маску. В просмотре выключенный A скрывает
прозрачность; только A показывает альфу в градациях серого; все каналы выключены — чёрный экран.
Переключение не меняет существующие пиксели и результат Save/Export. Новые мазки с маской —
обычные изменения рисунка с Undo/Redo. По умолчанию и после Reset все каналы включены.

Выдели **Drawing Layer** и рисуй прямо на превью. При этом виден результат всей композиции
с учётом порядка слоёв, режимов смешивания и эффектов.

- `ЛКМ` использует выбранный Brush/Eraser; `ПКМ` временно включает ластик.
- **Size**, **Hardness** и **Step** задают размер, жёсткость и расстояние между отпечатками кисти.
  Step измеряется в процентах от диаметра кисти.
- Два цветовых поля хранят основной и дополнительный цвет; `X` меняет их местами.
- `Shift` во время рисования фиксирует горизонталь или вертикаль; `Shift`-клик
  соединяет предыдущую точку с новой прямой линией.
- **Live Quality** задаёт разрешение превью во время мазка: **12,5–100%**, по умолчанию **37,5%**.
  Уменьшение снижает нагрузку на превью, не меняя экспорт и размер сохранённого холста.

### Симметрия и повторяющиеся мазки

Задай нормализованный **Center** и комбинируй настройки:

| Настройка | Поведение |
| :--- | :--- |
| Mirror X / Mirror Y | Отражение относительно вертикальной / горизонтальной оси через Center. |
| Horizontal / Vertical | Повторение в ряд или столбец. |
| Grid | Сетка с независимым количеством копий по X/Y. |
| Radial | Повторение по кругу с настраиваемым количеством секторов. |
| Copy / Alternate Mirror | Обычные копии / отражение каждой второй ячейки или сектора. |
| Continue / Clip | Продолжать мазок за границами / ограничить ячейкой или сектором, где мазок начался. |

При рисовании из отражённой ячейки активная копия остаётся под курсором.

<details>
<summary>Поведение прямых линий и хранение рисования</summary>

Чтобы начать отдельную горизонтальную или вертикальную линию, поставь начальную точку без `Shift`,
затем зажми `Shift` при перетаскивании. Первое движение определяет ось в пространстве холста.
Последовательные `Shift`-клики образуют соединённые отрезки. Ластик, шаг кисти, симметрия
и повторение применяются и к прямым линиям.

Clip ограничивает соединение формой повторения, содержащей начальную точку.
Undo/Redo, очистка слоя и смена документа сбрасывают точку соединения. Линии не продолжаются
между разными рисовальными слоями или размерами холста.

Текстуры рисования хранятся как вложенные ассеты документа и переносятся вместе с композицией.

</details>

<a id="transform"></a>
## Трансформ и пивот

Выдели любой слой, кроме группы, и включи **Transform** в шапке превью или нажми `T`.

- Тяни внутри рамки для перемещения; восемь маркеров меняют размер, круглый маркер вращает.
- Перемещай **золотой крестик пивота**, не сдвигая видимое изображение.
- Пивот притягивается к девяти точкам: углам, серединам сторон и центру.
  `Ctrl` временно отключает привязку.
- `Shift` ограничивает перемещение осью, сохраняет пропорции при масштабировании
  или вращает с шагом 15°.
- `Escape` отменяет перетаскивание; `T` / `Enter` выходит из режима.
  Пока Transform активен, рисование приостановлено.

**Tiling:** Clip оставляет область вне рамки прозрачной; Repeat повторяет текстуру;
Mirror чередует отражённые копии; Source наследует режимы исходной текстуры, включая
отдельные настройки U/V. Source с Clamp растягивает крайние пиксели, в отличие от прозрачного Clip.
По умолчанию остаётся Clip. Настройка влияет на превью и экспорт, но не меняет импорт источника.

**Filter:** Source (по умолчанию) наследует Filter Mode назначенной текстуры; Point сохраняет
чёткие границы пикселей; Bilinear сглаживает выборку; Trilinear дополнительно смешивает
существующие mip-уровни. Без mip-карт Trilinear работает как Bilinear. Filter независим от Tiling,
сохраняется при Reset трансформа и доступен в настройках Transform и его тулбаре в Preview.
Для процедурных слоёв Source использует Bilinear; настройки импорта текстур не меняются.

**Original Aspect** рядом с Reset в настройках слоя и в тулбаре визуального Transform
восстанавливает пропорции источника внутри текущей рамки, уменьшая одну ось. Центр изображения,
пивот, вращение, отражение и тайлинг сохраняются. Для File используются размеры исходной текстуры,
для Drawing — сохранённых пикселей, для процедурных слоёв — пропорции холста. Без источника File
или при нулевом/близком к нулю масштабе кнопка неактивна. Изменение поддерживает Undo/Redo.

<details>
<summary>Подробности трансформа</summary>

Рамка охватывает весь исходный холст, включая прозрачные пиксели. Её параметры соответствуют
полям Position, Scale и Rotation в настройках слоя. Каждое перетаскивание — одна операция Undo.

Position измеряется в пикселях результата, Pivot — в нормализованных координатах,
Scale — множитель, Rotation — градусы. Пивот может находиться вне рамки;
радиус привязки — 10 UI-пикселей. При нулевом или близком к нулю масштабе его перемещение отключено.

Для Drawing тайлинг трансформа создаёт отображаемые копии; рисование изменяет основную ячейку.
Повторение кисти — отдельная функция.

</details>

<a id="effects"></a>
## Outline, SDF и смешивание

**Outline и SDF** используют элемент непосредственно под ними в той же группе
либо конкретный выбранный слой или группу. Для группы объединяется альфа видимых
потомков без отдельного смешивания цвета. Ссылки на себя и циклические зависимости запрещены.

Метрики расстояния: **точный Euclidean EDT**, приближённый Euclidean
(8-связная chamfer-метрика), Manhattan и Chebyshev. Ширина, мягкость и максимальное
расстояние измеряются в пикселях результата. Обработка использует Burst и Native Collections:
параллельные проходы точного EDT и прямую запись в выходной буфер.

**Режимы смешивания** используют source-over альфу:
RGB смешивается в областях пересечения, а вне пересечения остаются цвет и альфа
того слоя, который присутствует в этой точке.

<details>
<summary>Все режимы смешивания и модификаторы</summary>

Normal · Add · Subtract · Multiply · Divide · Screen · Overlay · Darken · Lighten ·
Color Dodge · Color Burn · Linear Dodge (Add) · Linear Burn · Linear Light ·
Linear Light Add/Sub · Vivid Light · Pin Light · Hard Mix · Hard Light · Soft Light ·
Difference · Exclusion · Negation.

- **None** оставляет композицию без изменений.
- **Overwrite** заменяет весь RGBA-пиксель; прозрачность слоя интерполирует между старым и новым пикселями.
- **FX-модификаторы** — материалы или Shader FX-ассеты, применяемые по порядку после трансформа слоя.

Сериализованные значения Normal, Multiply и Overwrite сохранены для совместимости со старыми документами.

</details>

### Shader FX

Можно написать фрагментный эффект без полного шейдера и отдельного материала:

1. Выберите слой и нажмите **+ Shader FX** в разделе **FX** его настроек.
   Отдельный файл и диалог сохранения не нужны — даже у несохранённого документа.
2. Напишите `ApplyFX` и добавьте параметры прямо в настройках слоя. **Apply** компилирует
   эффект и обновляет превью; **Save / Ctrl+S** сохраняет его внутри документа композитора.
3. Значения параметров обновляют превью сразу. Код и объявления параметров остаются
   черновиком до **Apply**; при ошибке компиляции продолжает работать последний успешный вариант.

В редакторе кода работают `Ctrl+Z`, `Ctrl+Y` и `Ctrl+Shift+Z` (`Cmd` на macOS), через общую
историю Undo Unity. Непрерывный ввод объединяется; паузы, перемещение курсора, вставка,
вырезание и замена выделения разделяют шаги. Undo/Redo восстанавливает курсор и выделение
без перестройки поля. Меняется только черновик: для компиляции восстановленного кода нажмите **Apply**.

Например, добавьте параметр **Float** с именем `_Amount` и используйте:

```hlsl
float4 ApplyFX(float2 uv, float4 color)
{
    return float4(lerp(color.rgb, 1.0 - color.rgb, saturate(_Amount)), color.a);
}
```

Доступны **Float**, **Color**, **Vector** и **Texture2D**. Их uniform-переменные генерируются
автоматически — объявлять их повторно не нужно. Каждое нажатие **+ Shader FX** создаёт эффект,
принадлежащий документу. **Save As** независимо копирует встроенные FX и их шейдеры. Внешние
переиспользуемые FX по-прежнему доступны через **+ Reference**; их изменение влияет на все слои с этим FX.
Кнопка **Embed** заменяет ссылку на внешний FX независимой копией внутри документа,
не изменяя и не удаляя исходный ассет.
`SampleInput(uv)` читает входное изображение слоя с предыдущими модификаторами. Возвращайте
**straight RGBA**, без умножения RGB на альфу; прозрачность и смешивание слоя применяются после FX.
Каждый FX — один GPU-проход без чтения пикселей на CPU.

Для HLSL-библиотек используется обычный `#include`: пути проекта, пакетов или относительные пути в кавычках:

```hlsl
#include "Assets/Shaders/MyLibrary.hlsl"
// Или: #include "Packages/com.example.library/Shaders/MyLibrary.hlsl"
// Или: #include "./MyLibrary.hlsl"  // Относительно документа или отдельного FX-ассета.
```

Вложенные подключения и include guards обрабатывает препроцессор Unity. Поддерживается и
`#include_with_pragmas`. Обёртка уже подключает `UnityCG.cginc`. Библиотека должна быть совместима
с этим окружением фрагментного шейдера: полный ShaderLab-шейдер или библиотека, зависящая от
конкретного render pipeline, не становятся автоматически переносимым набором функций.
До первого сохранения документа относительные пути отсчитываются от **Assets**.
После изменения библиотеки снова нажмите **Apply**. После сохранения в другую папку проверьте
относительные пути перед повторным применением; ранее применённый шейдер остаётся доступным.

Встроенные входы: `_MainTex`, `_MainTex_TexelSize`, `_InputSize` и `_CanvasSize`
(`ширина, высота, 1/ширина, 1/высота`), а также `_PreviewScale` — число пикселей результата на пиксель превью.
Для согласованного результата в уменьшенном превью и экспорте задавайте расстояния относительно холста.
Код, параметры и скомпилированные шейдеры встроенных FX хранятся внутри `.asset` композитора;
изменение значений и рендер не генерируют шейдеры заново. У внешних FX сохраняется отдельный `.asset`.
После редактирования FX сохраните композитор ещё раз, чтобы обновить его встроенную выходную текстуру.

<a id="export"></a>
## Форматы экспорта

| Формат | Прозрачность и особенности |
| :--- | :--- |
| **PNG** | Прозрачность сохраняется. |
| **TGA** | Прозрачность сохраняется. |
| **JPEG** | Белый фон, качество 95. |
| **EXR** | Линейный RGB + альфа, half-float с ZIP-сжатием. |
| **Texture2D (.asset)** | Читаемая нативная текстура Unity, отдельная от редактируемого документа. |

PNG/JPEG/TGA внутри `Assets` импортируются как одиночные Sprite, EXR — как линейная текстура.
Замена существующего самостоятельного Texture2D требует подтверждения и сохраняет ссылки на него.
Другие типы ассетов и вложенные ассеты защищены от перезаписи.

> [!NOTE]
> Композиция рассчитывается в 8-битном RGBA. Экспорт в EXR не добавляет HDR-диапазон
> и не восстанавливает потерянную точность.

<a id="shortcuts"></a>
## Горячие клавиши

| Сочетание | Действие |
| :--- | :--- |
| `Ctrl+S` | Save или Save As для нового документа. |
| `Ctrl+Z` | Отмена. |
| `Ctrl+Y` / `Ctrl+Shift+Z` | Повтор. |
| `[` / `]` | Уменьшить / увеличить кисть. |
| `X` | Поменять основной и дополнительный цвет. |
| `ПКМ` | Временный ластик. |
| `Shift` при рисовании / `Shift`-клик | Мазок вдоль оси / прямая от предыдущей точки. |
| `T` | Переключить визуальный Transform. |
| `Enter` / `Escape` | Выйти из Transform / отменить текущее перетаскивание. |
| `Ctrl` при перемещении пивота | Отключить привязку. |

На macOS для сохранения, выделения и Undo/Redo также работает `Cmd`.

Команды Unity Shortcut Manager приостанавливаются **только пока это окно в фокусе**,
чтобы не перехватывать клавиши рисования. Текстовые и числовые поля сохраняют обычный ввод.
При потере фокуса или закрытии окна хоткеи Unity восстанавливаются.
